CONTENT WORKSPACE / 静态发布

内容在 GitHub，
发布由提交完成。

这是一个无数据库、无网页登录密码的静态博客。文章、图片和友链都是仓库里的公开文件；合并或推送到 main 后，GitHub Actions 会自动部署到网站。

01 / 文章

新建或编辑 Markdown

每篇文章一个 .md 文件，支持标题、列表、引用、代码块和 ![图片说明](图片地址)。

新建文章 ↗ 查看文章库 ↗

02 / 图片

上传到仓库图片目录

上传图片到 uploads/，然后用相对路径插入文章，例如 ![照片](/uploads/2026/example.jpg)。

打开图片目录 ↗

03 / 友链

以 PR 的方式维护

友链直接陈列站点名称、头像和介绍。申请者按规范修改 JSON 并提交 Pull Request。

编辑友链 ↗ 申请规范 ↗

04 / 发布与回滚

查看每次发布状态

推送后自动发布；若健康检查失败，服务器会恢复上一个可用版本。需要时可在 Actions 页面指定提交版本回滚。

打开 Actions ↗
