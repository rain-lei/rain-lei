# 求实书院育人课程与学分认定指南

> **适用范围**：根据求实书院课程体系截图及现阶段课程通知整理，面向需要完成书院育人课程的学生。
>
> **使用边界**：本文用于梳理课程结构和已明确的完成方式，不代替书院正式培养方案、课程群通知或书院管理系统要求。尚未公布的上课时间、地点、认定清单和提交期限，统一标记为“待通知”。

## 一、先看总学分结构

书院育人课程由一门必修课和四个选修模块组成。

| 项目 | 学分要求 | 说明 |
| --- | ---: | --- |
| 大学学习与生活指导 | 必修 1 学分 | 书院通识课程，16 学时 |
| 四个育人模块 | 选修共 5 学分 | 每个模块至少修读 1 学分 |
| 课程类学分 | 至少 3 学分 | 四模块的 5 学分中，课程类至少占 3 学分 |
| 活动类学分 | 按认定规则计算 | 参加 8 次符合要求的活动，可按 1 学分认定 |

因此，按照截图所示结构，书院育人课程需要完成的总量为：

```text
1 学分必修课 + 5 学分模块选修 = 6 学分
```

四个模块都不能完全空缺。即使总学分已经达到 5 学分，仍需检查每个模块是否至少取得 1 学分。

## 二、四个育人模块

| 模块 | 课程类 | 活动类 |
| --- | --- | --- |
| 人格塑造与价值引领 | 实践开拓 | 人格塑造与价值引领活动类 |
| 知识融合与思维进阶 | 信息素养培养、交叉前沿 | 知识融合与思维进阶活动类 |
| 能力锻造与实践创新 | 创新创业 | 能力锻造与实践创新活动类 |
| 社会责任与领军意识 | 领导力执行 | 社会责任与领军意识活动类 |

截图中的课程类项目均为 1 学分、16 学时；四类活动项目均按 1 学分、24 学时设置。活动学分的具体活动范围和认定方法，以后续通知及系统清单为准。

## 三、五门课程一览

| 课程 | 所属模块 | 学分/学时 | 当前明确的完成方式 |
| --- | --- | ---: | --- |
| 领导力执行 | 社会责任与领军意识 | 1 学分 / 16 学时 | 单独排课，线上线下结合，按主讲教师要求完成结课 |
| 信息素养培养 | 知识融合与思维进阶 | 1 学分 / 16 学时 | 单独排课，按主讲教师要求完成结课 |
| 交叉前沿 | 知识融合与思维进阶 | 1 学分 / 16 学时 | 大三第二学期末前参加不少于 5 次校内报告、讲座或论坛，并提交材料认定 |
| 创新创业 | 能力锻造与实践创新 | 1 学分 / 16 学时 | 通过竞赛、技术认证、指定课程或大创项目中的一种路径申请认定 |
| 实践开拓 | 人格塑造与价值引领 | 1 学分 / 16 学时 | 完成书院指定的软硬件系统实践或芯片与系统开发实践课程 |

若五门课程全部完成，可以获得 5 个课程类学分，并覆盖全部四个模块；这是一条满足“每模块至少 1 学分、课程类至少 3 学分”的组合，但是否需要全部修读以及实际开放批次，以个人培养要求和书院管理系统为准。

## 四、课程 1：领导力执行

### 课程安排

- 当前安排在一年级第二学期，即 **1-2 学期**；
- 采用单独排课方式，不与普通教务课表安排混为一谈；
- 采用线上与线下结合的授课形式；
- 具体上课时间、线下地点和线上入口另行通知。

### 完成标准

课程结课按照主讲教师发布的要求完成。现有信息没有统一规定作业类型、考核形式或提交平台，因此不能预先假定为考试、论文或签到次数。

### 需要关注

- 课程群或书院通知中的排课信息；
- 线上平台入口和线下教室；
- 主讲教师公布的考勤、作业与结课要求；
- 课程完成状态是否同步到书院管理系统。

## 五、课程 2：信息素养培养

### 课程安排

- 当前安排在一年级第二学期，即 **1-2 学期**；
- 采用单独排课方式；
- 上课地点另行通知。

### 完成标准

按照主讲教师要求完成课程学习和结课任务。现阶段没有公布统一考核形式，应以任课教师实际通知为准。

### 与培养方案截图的关系

课程体系截图在“建议修读学期”中还标出了 2-2 和 3-2，表示培养方案允许在相应阶段安排；针对当前年级已经明确的安排仍以 **1-2 学期通知**为准。

## 六、课程 3：交叉前沿

交叉前沿不限定单一课堂或固定学科主题，主要通过参加校内学术与人文活动完成。

### 完成条件

在**大三第二学期结束前**，参加校内举办的报告、讲座、论坛等活动不少于 **5 次**。

活动范围包括但不限于：

- 学术研究报告；
- 工程技术讲座；
- 人文社会科学讲座；
- 学科交叉论坛；
- 学校、学院或其他校内单位举办的公开报告。

主题不受限制，主办单位也不限定为书院。关键条件是活动由学校内部单位举办，并且能够提供真实、完整的参加证明。

### 每次活动应留存的材料

| 材料 | 要求 |
| --- | --- |
| 活动通知 | 保留能够显示活动名称、时间、地点和主办单位的完整通知或海报 |
| 现场照片 | 留存本人参加讲座或论坛时的现场合影，画面应能识别活动场景 |
| 感悟体会 | 每次活动准备一份 500 字以内的真实感悟或学习记录 |

建议不要只保存群聊中的临时缩略图。活动结束后应尽快把原图、通知和文字记录归档，避免几年后无法确认活动信息。

### 学分认定

书院管理系统后续会上线对应选课或认定入口。已经完成 5 次活动并备齐材料的学生，可在入口开放后选课并提交材料申请认定学分。

参加活动本身不会自动生成学分；仍需在规定时间内完成系统选课和材料提交。

## 七、课程 4：创新创业

当前通知列出了四类可用于认定的完成路径，完成其中一种即可申请认定：

1. 在书院指定的科技创新竞赛中获得规定奖项；
2. 通过书院认可的第三方软件或硬件技术认证考试；
3. 完成书院指定的职业类或创业类课程并通过考核；
4. 立项一项符合要求的大学生创新创业项目。

### 认定时不能自行判断的内容

以下信息尚需等待书院公布清单：

- 哪些竞赛属于“指定科创竞赛”；
- 需要达到什么奖项等级；
- 哪些软件或硬件认证被认可；
- 哪些职业或创业课程可以计入；
- 大创项目要求校级、省级还是国家级；
- 仅立项即可认定，还是还需中期、结项或等级要求；
- 团队项目对本人排序或贡献的要求。

不在正式清单内的比赛、培训证书、商业认证或在线课程，不应默认可以认定学分。

### 建议留存的证明

- 竞赛通知、获奖证书和官方获奖名单；
- 技术认证成绩单、电子证书和证书查询页面；
- 指定课程的选课、考核和结业证明；
- 大创项目立项文件、项目成员名单及后续过程材料。

书院开放系统入口后，完成者需要选课并提交相应材料，经审核后认定学分。

## 八、课程 5：实践开拓

### 完成方式

完成书院指定的下列实践课程之一，并通过考核：

- 计算机软硬件系统实践课程；
- 芯片与系统开发实践课程。

“指定课程”意味着课程名称、开设单位和考核结果均需符合书院清单，不能用内容相近的普通课程自行替代。

### 系统认定

书院后续会通过管理系统开放选课。学生需要关注开放时间，完成选课、课程学习和考核，并检查学分认定结果。

现有通知没有给出课程名单、开课学期、容量、授课平台和补认定安排，这些信息以书院后续通知为准。

## 九、建议修读时间与当前安排

课程体系截图中的黑点表示建议修读学期，不等同于每一学年都会在所有标记学期开放。结合当前通知，可以按下表理解：

| 课程 | 截图中的建议修读学期 | 当前文字通知 |
| --- | --- | --- |
| 大学学习与生活指导 | 1-1 | 必修课，按实际课表完成 |
| 领导力执行 | 1-2、2-2、3-2 | 当前年级安排在 1-2，具体时间地点待通知 |
| 信息素养培养 | 1-2、2-2、3-2 | 当前年级安排在 1-2，具体地点待通知 |
| 交叉前沿 | 3-1、3-2、4-1、4-2 | 大三第二学期末前累计完成 5 次活动 |
| 创新创业 | 3-1、3-2、4-1、4-2 | 完成任一认定路径，等待系统开放 |
| 实践开拓 | 3-1、3-2、4-1、4-2 | 完成指定实践课程，等待系统开放 |

“建议修读学期”用于规划，不应被理解成刚性截止时间；文字通知已经明确截止时间的交叉前沿除外。

## 十、材料归档方法

建议从第一次参加活动或取得成果时就建立文件夹，而不是等系统开放后再补材料。

```text
书院育人课程/
├─ 01-领导力执行/
├─ 02-信息素养培养/
├─ 03-交叉前沿/
│  ├─ 01-讲座名称-日期/
│  │  ├─ 活动通知.png
│  │  ├─ 现场照片.jpg
│  │  └─ 感悟体会.md
│  └─ 02-讲座名称-日期/
├─ 04-创新创业/
│  ├─ 获奖或认证证明.pdf
│  └─ 官方通知或查询截图.png
└─ 05-实践开拓/
   └─ 课程与考核证明.pdf
```

文件名宜包含日期和活动名称。截图应保留完整页面信息，避免只截取局部导致无法确认主办方、时间或本人身份。

## 十一、系统认定的一般流程

```text
完成课程、活动或成果
  → 留存原始证明材料
  → 等待书院管理系统开放选课
  → 在规定时间内完成选课
  → 按课程要求上传材料
  → 等待书院审核
  → 核对学分认定结果
```

系统尚未开放不影响提前参加活动和整理材料，但系统开放后仍需主动选课、提交和检查审核结果。

这些事项应等待书院或主讲教师通知，不建议依据往年经验自行推断。

## 十三、一页式核对清单

- [ ] 完成“大学学习与生活指导”必修 1 学分。
- [ ] 四个模块合计取得 5 个选修学分。
- [ ] 每个模块至少取得 1 学分。
- [ ] 课程类学分不少于 3 学分。
- [ ] 查看 1-2 学期领导力执行的单独排课通知。
- [ ] 查看 1-2 学期信息素养培养的上课地点和结课要求。
- [ ] 大三第二学期末前完成不少于 5 次交叉前沿活动。
- [ ] 每次交叉前沿活动均保存通知、现场照片和 500 字以内感悟。
- [ ] 创新创业只按书院正式认定清单选择完成路径。
- [ ] 实践开拓只选择书院指定的实践课程。
- [ ] 书院管理系统开放后及时选课并上传材料。
- [ ] 审核结束后核对学分是否已经入账。
