## 关于我

我是一名软件工程学习者，喜欢把复杂的问题拆开，把有趣的想法做出来。

我关心的不只是“能不能运行”，也关心：

- 页面是不是足够清晰、舒服
- 代码是不是容易理解和维护
- 一个小工具能不能真正节省别人的时间
- 学到的东西，能不能留下来并帮助到别人
